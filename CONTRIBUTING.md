# Contributing

Contributions are welcome when they improve technical accuracy, clarity, accessibility, or maintainability.

## Content rules

- Use public primary documentation for product behavior.
- Distinguish documented behavior from engineering recommendation.
- Use original examples and diagrams.
- Do not add certification questions, answer keys, screenshots, or mappings to private source material.
- Avoid language implying official affiliation or guaranteed exam outcomes.
- Prefer durable architecture principles over version-specific trivia.

## Pull request checklist

- [ ] The change is written in original language.
- [ ] Time-sensitive claims have current primary sources.
- [ ] Internal links work.
- [ ] Diagrams have accessible alt text.
- [ ] The site builds with `npm run docs:build`.
